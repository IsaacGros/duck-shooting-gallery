# Duck Shooting Gallery

An arcade-style shooting gallery game built in **C++** using **Abonvita Software (GX Toolkit)** as a solo university coursework project for **COSC-4325**.

**Repository:** `https://github.com/IsaacGros/duck-shooting-gallery`

## Overview

This project implements a playable arcade shooting gallery built end-to-end as a solo developer, covering system planning, gameplay programming, 2D/3D asset production, audio integration, and debugging.

## Tools Used

- **Language & Engine:** C++, Abonvita Software (GX Toolkit)
- **IDE:** Visual Studio Community
- **Art & Audio:** Blender, Clip Studio Paint, Audacity

## Controls

- **Aim:** Move the mouse / cursor
- **Shoot:** Left Mouse Button
- **Move:** `WASD`
- **Exit:** `Esc`
